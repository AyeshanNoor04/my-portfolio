# Ayesha Noor — Personal Developer Portfolio

A clean, modern, and responsive personal portfolio website built to showcase my frontend development projects, technical skills, and web design work.

🔗 **Live Demo:** [https://ayeshanoor.netlify.app/](https://ayeshanoor.netlify.app/)

---

## ✨ Features

- **Responsive Design:** Fully optimized for desktop, tablet, and mobile screens.
- **Clean & Modern UI:** Minimalist dark-themed aesthetic with smooth navigation and structured layouts.
- **Projects Showcase:** Highlights key frontend and web development projects with live previews and source code links.
- **Skills & Contact Section:** Easy access to my tech stack and ways to connect.

---

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom styling, Flexbox, Grid & animations
- **Bootstrap** — Responsive layout components
- **JavaScript** — Interactive UI features
